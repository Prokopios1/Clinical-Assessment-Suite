# Clinical Assessment Suite - Android App

Native Android application for the Clinical Assessment Suite.

## Features
- Patient assessments (PHQ-9, GAD-7, PQ-B, MSI-BPD, PID-5-BF)
- Clinician dashboard with analytics
- Firebase integration

## Build
```bash
./gradlew assembleDebug
```

## Install on Device
```bash
./gradlew installDebug
```
